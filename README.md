# Netflix Clone

This is a responsive front-end clone of the Netflix landing page, built using HTML and CSS. It mimics the design and layout of the original Netflix homepage, showcasing sections like feature highlights, FAQs, and a footer with useful links.

## Features

- Fully responsive layout
- Styled buttons and call-to-action sections
- Embedded images and videos
- Multi-section layout: Hero, Features, FAQs, and Footer

## Technologies Used

- HTML5
- CSS3

## How to Use

1. Clone the repository.
2. Open `Netflixclone.html` in your browser.
3. Make sure to include the `style.css` and assets for full functionality.

> Note: This is a static front-end project and does not include any backend or streaming functionality.
